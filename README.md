# 在线札记

科研工作台的独立浏览器编辑器。网页是公开的静态文件，但**不包含笔记、令牌或个人数据库**。笔记保存在用户自行指定的 Gitee 私有仓库中。

打开 [在线札记](https://fasuiker.github.io/research-workspace-notes/)，输入 Gitee 私有仓库的网址和有仓库读写权限的私人令牌即可使用。不要将令牌写入此仓库、笔记或截图；只在自己信任的设备上使用。

这个网页不需要云服务器。首次使用前，应先在本地科研工作台「设置 → 札记跨设备同步」连接同一 Gitee 私有仓库并执行一次同步。网页编辑后，本地工作台会定期拉取变化，也可手动点「立即同步」。

静态前端由科研工作台项目生成。第三方库的许可证位于 `vendor/` 对应目录。
